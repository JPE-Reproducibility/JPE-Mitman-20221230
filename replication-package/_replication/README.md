## Overview

The code in this replication package constructs the analysis files and
reproduces every exhibit in the paper and the online appendix from five data
sources — the Survey of Consumer Expectations (Federal Reserve Bank of New
York, 2026), the Survey of Professional Forecasters (Federal Reserve Bank of
Philadelphia, 2026), the Panel Study of Income Dynamics (Survey Research
Center, 2026), the Current Population Survey (U.S. Census Bureau and U.S.
Bureau of Labor Statistics, 2026), and a set of FRED series — using R, Stata,
and MATLAB.

The package has two branches, each with its own master file, and one shell
script at the root that runs both:

| Branch   | Master file             | Reproduces                                      |
| -------- | ----------------------- | ----------------------------------------------- |
| `_data`  | `_data/data_master.R`   | Section 2, Online Appendix A, Table B.2 panel (a), Table III data column |
| `_model` | `_model/model_master.m` | Sections 4, 5, 6, Online Appendices B, C, D     |

Together they produce the 8 main-text figures, 6 main-text tables, 7 appendix
figures, and 17 appendix tables in the article. The replicator should expect
the data branch to run in about 20–40 minutes and the model branch in about
60–70 hours; see [Computational requirements](#computational-requirements).

### Details on each Data Source

#### 1. Survey of Consumer Expectations (SCE)

The SCE is a monthly internet survey of approximately 1,300 household heads
run by the Federal Reserve Bank of New York. We use two modules and merge them
on the household identifier: the **core monthly expectations module** and the
**supplemental household finance module**. The merged sample covers 2013M8 to
2020M1.

- **Access:** free, no registration.
- **Core microdata:** <https://www.newyorkfed.org/microeconomics/sce#/> —
  click "Downloads", then "Complete Microdata 2013-2016", "Complete Microdata
  2017-2019", and "Latest Microdata".
- **Household finance module:**
  <https://www.newyorkfed.org/microeconomics/databank.html> — click "SCE
  Household Finance Survey", then "Complete Microdata".
- **Provided in package:** yes —
  `_data/_data/FRBNY-SCE-Public-Microdata-Complete-13-16.csv`,
  `FRBNY-SCE-Public-Microdata-Complete-17-19.csv`,
  `FRBNY-SCE-Public-Microdata-latest.csv`, and
  `SCE_public_HH-finance_quarterly_microdata.xlsx`.
- **Date accessed:** 1 January 2026.
- **Citation:** Federal Reserve Bank of New York (2026).

#### 2. Survey of Professional Forecasters (SPF)

Used to construct the consensus professional forecast that proxies the true
probability of rising unemployment (variable `PRUNEMP`) and the inflation
forecast moments in Table A.10.

- **Access:** free, no registration.
- **URL:**
  <https://www.philadelphiafed.org/surveys-and-data/real-time-data-research/survey-of-professional-forecasters>
  — under "BASELINE VARIABLES", click "Download one variable at a time", then
  e.g. "Probability of Changes in GDP Price Index (PRPGDP)" and "Probability
  of Changes in Unemployment (PRUNEMP)".
- **Provided in package:** yes — `_data/_data/PROB_SPF_RAW.xlsx` (unemployment
  probabilities) and `_data/_data/PROB_SPF_RAW_INF.xlsx` (inflation
  probabilities).
- **Date accessed:** 1 January 2026.
- **Citation:** Federal Reserve Bank of Philadelphia (2026).

#### 3. FRED macroeconomic series

Realizations of macroeconomic outcomes, used to compute household forecast
errors, to estimate the forecasting BVAR, and to construct the empirical
business-cycle moments of Table B.2 panel (a).

- **Access:** free, no registration.
- **URL:** <https://fred.stlouisfed.org/>
- **Series read by the code:** `CPIAUCSL` and `CPILFESL` (prices),
  `CSUSHPINSA` (house prices), `UNRATE` (unemployment, with real-time
  vintages from ALFRED), `CE16OV` and `CNP16OV` (employment and population),
  `FEDFUNDS` (policy rate), `GDPC1` (real output), and `PRS85006023` (hours).
- **Series entering Table B.2 panel (a)** via
  `_data/_data/business_cycle_data.xlsx`: `A939RX0Q048SBEA` (real GDP per
  capita), `A794RX0Q048SBEA` (real consumption per capita),
  `NFIRSAXDCUSQ` (real gross fixed capital formation), and
  `RKNANPUSA666NRUG` (capital stock at constant national prices).
- **Provided in package:** yes — `_data/_data/*.xls` and
  `_data/_data/_data_var/*.xls`, one workbook per series, plus the summary
  workbook `_data/_data/business_cycle_data.xlsx`, whose first sheet holds the
  assembled quarterly series and whose remaining sheets hold the raw FRED
  downloads with their series identifiers and vintage dates.
- **Date accessed:** 1 January 2026.
- **Citations:** see [References](#references); each series is cited to its
  originating agency.

#### 4. Panel Study of Income Dynamics (PSID)

Used for the wealth and expenditure distribution in Table III. The extract
here was not built from the raw PSID files: it was taken from the replication
materials of Krueger, Mitman, and Perri (2016), "Macroeconomics and Household
Heterogeneity", *Handbook of Macroeconomics*, Vol. 2, and covers 2004–2010.

- **Access:** free, but direct download of PSID microdata requires
  registration at <https://psidonline.isr.umich.edu/>. No registration is
  needed to use this package, since the extract is redistributed here.
- **Provided in package:** yes — `_data/_data/psid_2004_2010.dta`, with a
  non-proprietary copy at `_data/_data/psid_2004_2010.csv`.
- **Date accessed:** 1 January 2026.
- **Citation:** Survey Research Center (2026).

#### 5. Current Population Survey (CPS)

Used for the U.S. labor-market transition rates (unemployment-to-employment
flows of 55 and 45 percent) that discipline the model's employment
transitions in Section 4. These enter the code as calibrated parameter values
in `_model/_aux/_baseline/modelsMasterExcel.xlsx` rather than as a dataset
read at run time, so no CPS extract is redistributed.

- **Access:** free, no registration.
- **URL:** <https://www.census.gov/programs-surveys/cps.html>
- **Provided in package:** no — used only as a calibration target.
- **Date accessed:** 1 January 2026.
- **Citation:** U.S. Census Bureau and U.S. Bureau of Labor Statistics (2026).

## Computational requirements

### Software Requirements

- **R** 4.5.1 (used with RStudio 2025.05.01+35)
  - Packages: `AER`, `dplyr`, `foreign`, `ggplot2`, `haven`, `jtools`,
    `lmtest`, `matrixStats`, `mgcv`, `plm`, `plyr`, `pracma`, `R.matlab`,
    `readxl`, `restriktor`, `sandwich`, `stargazer`, `tidyverse`
  - Run `_data/packages_rstudio.R` once before `data_master.R`; it installs
    every package above that is not already present.
- **Stata/MP** 17.0
  - No user-written (`ssc`) commands are required; `make_table3_data.do` uses
    only official Stata.
- **MATLAB** R2024b or later (developed on R2024b and R2026a)
  - **Econometrics Toolbox** — `bayesvarm`, `estimate`, `simulate`
    (`_data/_aux/bvar_est.m`); `hpfilter`, `autocorr` (business-cycle and
    inequality moments in both branches)
  - **Statistics and Machine Learning Toolbox** — `corr`, `regress`, `fitlm`,
    `prctile`, `normcdf`, `normpdf`, `fitdist`
  - **Optimization Toolbox** — `fsolve` (`BKKS_main.m`, entrepreneur model)
  - **Symbolic Math Toolbox** — `eulergamma` (`BKKS_main.m`, every model solve)
  - **Parallel Computing Toolbox** — `parfor` in `solve_EGM.m` and
    `solve_experience.m`; `parpool` in `figure_d1.m`. Without it `parfor`
    degrades to a serial loop and the model branch runs substantially slower.

Portions of the code use the third-party function `wprctile.m` (weighted
percentiles, MATLAB File Exchange), redistributed in
`_model/_aux/_baseline/` and `_model/_aux/_kvar/`.

### Controlled Randomness

Random seeds are set in three places, and no other program in the package

| `rng(1)` | `_data/_aux/bvar_est.m` | Posterior draws of the forecasting BVAR |

#### Summary of required storage space

- [ ] <25 MBytes
- [ ] 25 MBytes – 250 MBytes
- [ ] 250 MBytes – 2 GBytes
- [ ] 2 GB – 25 GBytes
- [x] 25 GBytes – 250 GBytes

The distributed package is under 1 GB. Running the model branch writes
intermediate results to `_model/_aux/_models_tmp/`, which grows to
approximately 90 GB: the solved-model `.mat` files reach 6–9.5 GB each once
they carry the simulation panels, and the two shock panels are ~7.8 GB each.
**Ensure at least 100 GB of free disk before running `model_master.m`.**

The solved models distributed in `_model/_aux/_models_tmp/` have been reduced
to about 0.33 GB in total by dropping the four large simulation-panel objects
(`cah_panel`, `kdist_panel`, `pKdist_panel`, and the `forecast_moments`
field `fcerror_ur_up_4q_panel`) and the two regenerable shock panels. What
remains is everything the solver needs to warm-start a re-solve and everything
the output programs read apart from the panels themselves. The utility that
performed this reduction is included as `_model/_aux/slim_models_tmp.m`.

**Consequence for partial reruns.** Because the panels are not distributed,
step [3] of `model_master.m` cannot be run on its own for the exhibits that
read panel data: Figures 3, 4, 6, 7, 8, B.1, B.2, C.1–C.4 and D.1, and
Tables III and C.3. Running `model_master.m` from the top is self-healing —
step [1] rebuilds the shock panels and step [2] re-solves the models before
any output program runs.

#### Computational Details

The model was run on an Apple M1 MacBook Pro with 64 GB of RAM under macOS,
and the data branch on a 2021 MacBook Pro with 64 GB of RAM. Memory, not CPU,
is the binding constraint on the model branch: at the shipped calibration
(*N* = 25,000 agents, *T* = 20,000 periods) each double-precision *N* × *T*
panel is about 4 GB, and a single solve holds several of them simultaneously.
**Budget 45–50 GB of RAM per model solve.** The solves are sequential; the
parallelism is within a solve, through `parfor`, and uses whatever worker
count the local cluster profile defaults to.

### The data branch

`_data/data_master.R` runs the data build and then the analysis programs, in
this order. The build order is mandatory: each step consumes the previous
step's output.

1. `_aux/bvar_data.R` — assembles the quarterly macro panel (CPI inflation,
   real GDP growth, unemployment, the federal funds rate, hours) from the FRED
   workbooks into `_aux/data_bvar.csv`.
2. `_aux/bvar_est.m` — estimates the Bayesian VAR and writes the model-implied
   probability of rising unemployment to `_aux/prob_up_bvar.csv`.
3. `_aux/spf_data.m` — builds the SPF consensus probability of rising
   unemployment, `_aux/spf_prob_u.csv`. (The companion inflation moments,
   `_aux/spf_infl_moments.csv`, are distributed with the package rather than
   rebuilt here; see the dataset list above.)
4. `_aux/sce_data.R` — merges the SCE core and household finance modules,
   constructs net financial wealth, forecast errors, and the wealth bins, and
   writes the analysis sample `_aux/data_sce.rda`.
5. The seven analysis programs, then `table_b2_a.m` and `make_table3_data.do`.

### The model branch

`_model/model_master.m` runs in three steps:

1. **Regenerate the shock panels.** `make_shocks.m` rebuilds
   `_aux/_models_tmp/NewShocks.mat` and `NE3Shocks3.mat`. This must happen
   first: every model solve loads one of them, and they are too large to
   distribute. It needs only the `params` struct from the distributed
   `model_1001.mat` and `model_7009.mat`, which the slimmed files retain.

2. **Solve the models.** `_aux/_baseline/BKKS_start_runs.m` solves 26 models
   and `_aux/_kvar/BKKS_start_runs.m` solves 3 more, writing each to
   `_aux/_models_tmp/model_<id>.mat`. The identifiers and their calibrations
   come from the two `modelsMasterExcel.xlsx` workbooks — the same
   parameterisation reported in Table B.1. The blocks must run in order:
   later blocks warm-start from `.mat` files written by earlier ones.
   `_aux/_baseline/InfoDecomposition.m` then decomposes the entrepreneur
   model into its full-information and exogenous-information counterfactuals,
   holding the law of motion at `model_7009`'s own, and writes
   `_aux/_models_tmp/model_7009_decomp.mat` for Table C.11.

   The solution method is a Krusell–Smith global solve with endogenous
   information acquisition. `BKKS_main.m` iterates on a two-regime log-linear
   law of motion for aggregate capital; inside each iteration
   `solve_policies.m` alternates an endogenous-gridpoint consumption–savings
   solve (`solve_EGM.m`) with an experience-utility value-function solve
   (`solve_experience.m`), whose buy-versus-not-buy value gap maps through a
   logit into the information-acquisition probability; `simKS.m` then
   simulates the cross-section and the law of motion is updated.

3. **Produce the output.** Each `table_*.m` and `figure_*.m` program loads the
   solved models it needs and writes to `_table/` or `_figures/`.

## Instructions to Replicators

### Checking your setup first

Before committing to a long run, confirm the three interpreters are visible
and that there is enough free disk:

```bash
./run_all.sh check
```

### Running everything

From the package root:

```bash
./run_all.sh
```

This runs the data branch and then the model branch, writing logs to
`_logs/`. Because the model branch takes 60–70 hours, run it detached:

```bash
nohup ./run_all.sh > _logs/run_all.log 2>&1 &
```

Either branch can be run on its own:

```bash
./run_all.sh data
./run_all.sh model
```

`run_all.sh` locates R, MATLAB, and Stata automatically. If they are installed
somewhere unusual, point it at them:

```bash
RSCRIPT_BIN=/usr/local/bin/Rscript \
MATLAB_BIN=/Applications/MATLAB_R2024b.app/bin/matlab \
STATA_BIN=/Applications/Stata/StataMP.app/Contents/MacOS/stata-mp \
./run_all.sh
```

### Running the branches by hand

Install the R packages once, then run each master file with the working
directory set to its own folder:

```bash
cd _data   && Rscript packages_rstudio.R && Rscript data_master.R
cd ../_model && matlab -batch "model_master"
```

Inside RStudio, open `_data/data_master.R` and source it with the working
directory set to `_data`. Note that RStudio locks the working directory of a
session to the first folder in which a file is sourced; restart RStudio before
sourcing files from a different folder.

### Details on various programs

- **Order between the branches.** `_data/figure_6_data.R` writes
  `_model/_aux/_models_tmp/figure_6.csv`, which `_model/figure_6.m` and
  `_model/figure_b2.m` read. Run the data branch before the model branch, as
  `run_all.sh` does.
- **Exhibits assembled from more than one program.** Three exhibits are
  produced in pieces and concatenated for typesetting:
  - *Table III* — data column from `_data/_tables/table3_data.tex`, model
    columns from `_model/_table/table_iii_model_base.tex` and
    `table_iii_model_ent.tex`.
  - *Table B.2* — panel (a) from `_data/_tables/table_b2_a.tex`, panel (b)
    from `_model/_table/table_bii.tex`.
  - *Figure 1, Figure 2, Figure 3, Figure 4, Figure 5, Figure 7* — panels are
    written as separate PDF files and placed side by side in the manuscript.
- **Panel naming for Figure 7.** `figure_7.m` writes `figure_7a.pdf` through
  `figure_7d.pdf`; these appear in the paper as, in order, the productivity,
  capital, output, and investment impulse responses
  (`_paper/_input/figure_IRF_prod2.pdf`, `figure_IRF_k2.pdf`,
  `figure_IRF_y2.pdf`, `figure_IRF_inv2.pdf`).
- **Tables written as text.** Tables A.7–A.10, C.3, and C.11 are written as
  fixed-width or tab-delimited text (`.txt`) rather than LaTeX; the values in
  those files are what the corresponding `.tex` files in `_paper/_input/`
  typeset.
- **Rounding.** Some reported estimates are rounded relative to the raw
  program output.
